Prospective registration, October 20, 2026. 0056 failed its gate: relocation
improved 24/48 constant-safe forecasts to 31/48, with 13 hazard detections but
six false alarms. This new factorial diagnostic tests two specific distractions
while retaining question-local current facts. It does not reclassify 0056.

Build another 48 synthetic poses / 24 mirrors using 0056's bounded-jitter
construction with seed 2026102057. Retain the same physical setup, private

All four arms use state={} and current facts inside one structured binary
question. Keep the same common factual locator, required forecast task and
semantic criteria. Cross two fixed changes:

- `local_baseline`: exact full local question from 0056.
- `no_guide`: remove the quoted damped driving guide and its reference wrapper;
  retain the entire required prediction task.
- `no_badges`: remove only road.on_road and physics.current_surface from the
  otherwise complete factual object; keep the full guide and task.
- `both_focus`: apply both changes. This is the primary candidate.

The two removed badges describe the current state. Other physical facts can
still imply current road contact; this is not removal of all current-safety
information. Guide removal changes text length and content together. No new
rule, worked example, future-state feature, evaluated risk flag or control
recommendation is supplied.

24 arm permutations twice, once with each criterion first. Shuffle case units
and the permutation/menu assignments with seed 2026102057. Criteria order is
identical within a case unit. This globally balances arm positions and menu
polarity; subgroup order balance is reported, not assumed. Mirrors and shared
templates remain correlated. There is one response per arm/case, not repeated
reliability evidence.

Freeze all exact payloads, order, route, source/helper hashes, local mocks,

The primary both_focus gate requires at least 40/48 correct, at least 20/24
