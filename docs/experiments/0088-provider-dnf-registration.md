# 0088: provider-DNF demo release

Prospectively registered after root audited and closed the failed 0087 attempt.
The user explicitly selected “Retire failed kart; others finish” after being told
about Clef's provider concurrency rejection. This release implements that
requested behavior. It does not reopen 0087 or any older study.

Two fixed entries: one validation rehearsal and one manually started stage
race, each consumed once before dispatch. No retry of an individual request,
replacement race, alternative model/provider, backoff loop or supplied control
is allowed. Both expire at midnight Pacific; admission requires fifteen minutes
remaining. Each is capped at 180 seconds and 1,100 native requests per kart.

Jev / OpenAI Decisions / Clef, pinned OpenRouter providers, standard oval,
seed zero, ghost grid -4/0/4 m, three laps, goal-only facts, and all optional
geometry/motion/timing packets remain fixed. No handling, physics or model
questions change. Live spectator publication reuses the latest exact sample and
bounded trail; whole-history timing statistics are computed after stopping.
Live p95 and infrastructure validity remain explicitly incomplete until then. Conventional Temporal workers, Local Activities, AgentCore
byte-preserving dispatch and real MCP controls remain in use.

An HTTP 408/429/500/502/503/504/529 or a transport failure terminates only that
racer's future requests. Its kart holds its last native input under unchanged
physics and rescue rules. The UI marks the provider DNF and reason. There is no
retry, new steering/pedal command, fallback or fabricated finish. Other drivers
continue until they finish or the declared deadline ends. A kart that already
finished is still a finisher. Invalid HTTP-200 native answers, route mismatches,
source changes and application errors continue to stop the entire race.

Full failure accounting is preserved. Every unreported bill retains its full
route reservation and increments uncertainty. The initial boundary is
99,410 requests / $11.525691428002778 / 333,938,714 tokens / 72 uncertainties,
no pending. Caps stay $20 / 110,000 requests / 500 million tokens, with the
1,000-request / five-million-token admission floors unchanged.

Root must observe and fully audit the rehearsal's process exit before enabling
the stage entry. Known provider DNFs are allowed after that review only when
all their full reservations remain charged, every raw/native/frame/budget
transition passes, the exact reviewed ledger remains unchanged, and no pending
reservation exists. New unreviewed errors or uncertainty do not admit work.
This policy is finite; remaining budget authorizes no extra entry.

Before actual dispatch, run the full source/boot/server-bound free clock gate,
a real Temporal injected-provider-failure check, a complete free provider-DNF
race, and the exact free Temporal Cloud / AgentCore / MCP interface. Native
choices remain direct and auditable. All earlier failures stay retained.

Finishers may be compared within this one run; an upstream provider DNF is an
infrastructure outcome and does not prove that model's driving policy is worse.
