Four arms,96 calls, one per pose/arm:

- `baseline`: exact0045 pedal-example questions and grouped shared facts;
- `structured_shared`: the same instruction text under a named `rules` field,
  with the same grouped facts still in shared state;
- `question_full`: empty shared state; each question's structured instructions
  contain the same complete current facts under `current_facts`;
- `question_component`: empty shared state; each question contains only its
  existing factual component group under `current_facts`. No facts are
  calculated differently, no current answer or evaluated policy guard is
  included, and no native option is removed.
